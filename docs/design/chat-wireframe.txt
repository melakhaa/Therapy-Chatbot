SAJIWA - CHAT SCREEN WIREFRAME (REDESIGN)
============================================
Format: ASCII text wireframe
Scope: apps/mobile/app/chat.tsx and components/chat/*
Typography spirit: Cabinet Grotesk (mapped to PlusJakartaSans weight spectrum)
Hero architecture: Editorial Split
Components: Card Stacking, Inline Typography Images, Horizontal Accordions
Motion: Hover Physics (press), staggered entrance, scroll-linked feel

3. QUICK REPLY - HORIZONTAL ACCORDION STATES
--------------------------------------------

Collapsed (56px):
  +----+ +----+ +----+ +----+
  |(ic)| |(ic)| |(ic)| |(ic)|     icon only, chevron hidden
  +----+ +----+ +----+ +----+

Expanded (up to 280px):
  +-------------------------------+
  | (icon)  Label text        ...  |   icon + full prompt + sub-label
  +-------------------------------+

Motion: width interpolate 56 -> min(280, 75% screen), spring icon pop on press.

                entrance 280-350ms cubic-out, stagger 70-80ms
