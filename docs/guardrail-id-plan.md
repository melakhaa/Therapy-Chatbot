# Plan: Bahasa Indonesia–optimized guardrail

Branch: `feat/guardrail-id`

## Context

Crisis detection lives in `apps/backend/services/chatbot/guardrail.py`:

1. **Deterministic keyword net** — `is_crisis()`: ~80 Indonesian crisis phrases, normalized substring match, deliberately biased to false positives (a false positive shows the hotline card; a false negative lets a student in crisis talk to an LLM).
2. **Semantic router** — `guardrail` route (24 utterances) as fuzzy fallback.
3. **Hardcoded response** — hotline card (Into The Light Indonesia, Yayasan Pulih, IGD).

`core.semantic_router()` checks `is_crisis()` first, so every route decision passes through the keyword net.

## Problem

The keyword net underperforms on **colloquial Bahasa Indonesia**:

- Leet/alay spellings: `bunuh d1r1`, `m4ti aja`
- Letter elongation: `aku mau matiii`, `gak kuatttt`
- Slang variants: `idup` (hidup), `gw/gue/aq` (aku), `ga/nggak/gak` (tidak), `modar/mokad` (mati)
- Missing colloquial phrases: `cabut nyawa`, `udah diujung tanduk`, `mau ngelakuin apa-apa`

## Options considered

| Option | Verdict | Why |
|---|---|---|
| **Llama Guard 3/4** | ❌ Rejected | No Indonesian in the supported taxonomy languages (3); unproven for ID (4). Generic moderation taxonomy, not crisis triage. Adds an 8B+ model next to the 3B chat model — a regression in both cost and accuracy. |
| External moderation API (OpenAI/Perspective) | ❌ Rejected | Stack is deliberately local (Ollama, no cloud calls). Mental-health messages must not leave the machine. |
| Indonesian fine-tuned classifier (IndoBERT etc.) | ⏸ Later, if ever | Adds transformers/onnx dependency to a lean FastAPI stack. Only justified if keyword net + router still miss real crisis traffic after Phase 1–2. |
| LLM-as-judge (llama3.2 second opinion) | ⏸ Later, if ever | 3B model is a weak safety classifier; adds latency per message. Only as a non-blocking advisory layer, never as the sole gate. |
| **Harden the existing deterministic net** | ✅ Chosen | Zero new deps, deterministic, testable, and morphology coverage is already free via substring matching (`membunuh dirinya` ⊃ `bunuh diri`). |

## Phases

### Phase 1 — Normalize harder + widen the phrase net (core fix)

File: `apps/backend/services/chatbot/guardrail.py`

1. **`_normalize()` upgrades** (cheap wins covering most colloquial space):
   - Collapse letter elongation: `matiii` → `mati` (repeated chars > 2 → 2, then known doubles map).
   - Leet fold: `1→i`, `0→o`, `3→e`, `5→s`, `4→a`, `7→t` (before phrase matching).
   - Slang synonym map applied on the normalized text: `idup→hidup`, `gw|gue|aq|aku→aku` (keep `aku`, phrase matching handles it), `ga|gak|nggak|ngga→tidak`, `mokad|modar→mati`, `udah|uda|dah→sudah`, `pgn|pengen→ingin`.
   - Keep substring matching — do **not** switch to word boundaries; substring is what gives free affix coverage (`menggantungkan diri`, `menyayat-nyayat`).
2. **Phrase additions** (colloquial crisis vocabulary):
   - `cabut nyawa`, `akhiri idup`, `udah diujung tanduk`, `mau ngelakuin bunuh diri`, `lebih baik gw mati`, `rasanya mau mati`, `kebelet mati`, `nggak mau bangun lagi`, `capek hidup`, `udah nyerah`, plus elongation/leet-tolerant duplicates handled by normalization (no need to write them out).
3. **Semantic router**: add ~10 colloquial utterances to `guardrail_route` (`gw pengen mati aja`, `udah gak kuat idup`, `rasanya mau nyakitin diri`).

### Phase 2 — Regression tests

File: `apps/backend/tests/test_guardrail.py`

- Colloquial true positives: `bunuh d1r1`, `aku mau matiii`, `gw udah gak kuat idup`, `cabut nyawa aja`.
- False-positive guard stays green: `mati lampu`, `hp mati`, `baterai mati`, `matematika`, `aku capek banget`.
- Run: `venv/bin/python -m unittest discover -s tests -v`

### Phase 3 — (Optional, gated) LLM second opinion

**Do not build now.** Trigger only if real usage shows crisis paraphrases slipping through:

- Non-blocking `llama3.2:3b` classification prompt (strict JSON: `crisis|distress|normal`) on messages the keyword net rejects, appending to `guardrail_logs` for evaluation — never replacing the deterministic gate.
- Alternative: small IndoBERT mental-health classifier behind the same interface. Adds deps; evaluate trade-off first.

## Explicitly out of scope

- Llama Guard (see table above).
- Output/response guardrails — replies beyond crisis are generated by the local 3B model with fixed prompts; revisit only if a real incident occurs.
- Changes to the hotline card or `guardrail_logs` schema.

## Validation

1. `venv/bin/python -m unittest discover -s tests -v` (all suites green).
2. `venv/bin/python scripts/api_smoke.py` with full stack up.
3. Manual spot-check via `POST /guardrail/check` with the colloquial phrases above.
