# @prototype/utils

Pure helpers for the mobile app: stress detection, AI response parsing, phone numbers,
character reactions. No React Native imports — keep it platform-free.

- Unit tests live beside the source (`*.test.ts`) and run with `npm run test:unit` here, or
  `npm test` from the repo root. Keep them green when touching reaction or stress logic.

Conventions: [typescript](../../docs/typescript-conventions.md),
[npm workspaces](../../docs/npm-workspaces-conventions.md).
